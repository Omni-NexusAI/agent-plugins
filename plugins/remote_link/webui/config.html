Auto-Start
Automatically start Agent Zero's built-in Remote Control when the container boots. If a tunnel is already running, its existing URL is reused — never regenerated.
Link Provider
The provider used when auto-start launches Remote Control. Same list as the built-in Remote Control panel.

Start, stop, and live status are handled by the built-in Settings → Remote Control panel. This plugin only configures boot-time auto-start and the provider.
