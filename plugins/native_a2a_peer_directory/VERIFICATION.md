# Verification

Development candidate, November 5, 2026. This package is independent of Unifier.

The installed host's built-in a2a_chat requires an explicit URL and has no native
named-peer registry. Existing A0 Swarm remotes resolve labels inside its own
delegation tool but do not provide a dynamic contact list to a2a_chat. Automatic
semantic memory recall missed a verified native contact during ordinary requests;
obsolete work-folder probes and old chat messages then misled peer investigation.

This companion uses the host's supported temporary prompt-metadata hook only.
Configuration contains independently verified native contacts and secret reference
names, never credential values. Automated checks cover fail-closed identity, URL,
secret-reference and duplicate validation, configuration preservation, blank config,
temporary-only hook output, and invalid-config degradation.

Nine focused isolated checks passed. In the first live prompt, temporary contact
metadata and the native secret reference were present, and an ordinary request
without a supplied URL selected the intended native laptop contact despite
automatic memory recall timing out. Unifier was disabled. Exactly one native
call received a nonempty remote acknowledgment. The model then emitted only
reasoning/thoughts without tool_name/tool_args; native final-answer validation
requested repair. The diagnostic was paused on that warning before retries.
Named-peer discovery and the one-reply gate passed; final-answer acceptance
failed. This directory does not convert model prose into a successful task or
change the native response tool. No generated-answer reliability or universal
discovery is claimed.

The same ordinary default-chat request subsequently passed with the separate,
reviewed Native Tool Output Contract enabled for its independently verified
model. Unifier remained disabled: one native A2A call received the real laptop
reply and the agent returned it through native response.text without warnings
or retries in 116 seconds. This directory owns discovery metadata only; the
provider output contract remains a separate optional package.

The laptop owner also passed an ordinary default-chat request naming the desktop
without a URL/auth/schema hint. With the independently verified GLM output
contract and this directory enabled, and no Unifier installed, one native LAN
call received the requested acknowledgment and returned it via the native
response.message argument in 135 seconds, without warnings or resends. This is
one ordinary workflow in each direction, not sustained reliability evidence.
