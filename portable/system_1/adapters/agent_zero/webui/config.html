System 1
Finite-choice decisions use the selected backend. Agent Zero still validates and executes actions.
Backend status
Checks the selected decision service on request.
Decision preset
Starting values for confidence, timeout, and monitoring. Each can be adjusted below.
Action eligibility
Exact tool names and arguments that System 1 may select. An action can opt into sharing its result with the next decision or returning that result to the user. Other actions escalate to Main.
Actions per turn
Maximum System 1 actions before the next step goes to Main.
Observed result limit
Maximum characters from a tool result passed to the next System 1 decision when that action allows it.
Minimum choice probability
Lower confidence escalates to the normal model.
Backend timeout, seconds
Decision failures use the normal model.
Monitoring interval, seconds
Minimum time between bounded event checks.
Monitoring check limit
Maximum decisions per task while Main works.
Monitoring duration, seconds
Stops the decision lane after this duration.
Action precedence
When an auxiliary Tool model is enabled, choose which role evaluates a task first.
