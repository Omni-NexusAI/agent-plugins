System 1
Finite-choice decisions use the shared Decider Model. Agent Zero still validates and executes actions.
Decider status
Checks the shared decision service for the selected enabled mode.
Decision preset
Starting values for confidence, timeout, and monitoring. Each can be adjusted below.
Action eligibility
Configured tool names with fixed or validated request/result arguments. System 1 may choose these actions; Agent Zero executes them. Uncertain or open-ended steps go to Main. Set parallel_safe for each action that may run concurrently with other independent actions.
Utility fixed responses
Optional exact system/message pairs and predeclared response choices. Verified memory query and candidate-filter calls can also use Decider; uncertain and open-ended calls use Utility.
Actions per turn
Maximum System 1 actions before the next step goes to Main.
Observed result limit
Maximum characters from a tool result passed to the next System 1 decision when that action allows it.
Minimum choice probability
Lower confidence escalates to the normal model.
Backend timeout, seconds
Decision failures use the normal model.
Monitoring interval, seconds
Minimum time between bounded event checks.
Monitoring check limit
Maximum decisions per task while Main works.
Monitoring duration, seconds
Stops the decision lane after this duration.
Action precedence
When an auxiliary Tool model is enabled, choose which role evaluates a task first.
